# Collaboration Style: How Agent Sessions Work With This Researcher

Distilled from the 2026-07-30 to 2026-08-03 woz sessions (DOET ingest, results-restructure discussion, path-coding scheme with four adversarial verification rounds) and mirrored into the repo at the researcher's instruction (2026-08-03) so every environment sees it: local sessions on any machine, and the weekly cloud routines. This file guides interaction style only. It never overrides the workspace CLAUDE.md, the schema, project CLAUDE.md files, or command contracts.

The researcher named the mode themselves: "please bear with me for being meticulous with the progress." Method artifacts here must survive hostile peer review (a full journal reviewer panel, one self-identified expert) and pilot coders. Work that arrives pre-verified with residuals documented gets approved fast. Work that arrives polished but unstressed gets probed until it cracks.

## Decisions

- Decompose decisions into labeled items (the A1–A12 pattern) and present two or three options per item with one recommendation and its consequences. The researcher picks by label, sometimes overriding. Never bundle decisions.
- The latest word wins, cheaply. A "replace" decision was reversed to "feed" one message later; honor the newest instruction without friction and record reversals in the log as "considered and declined".
- Genuinely open theory calls (model structure, construct definitions) route to the colleagues or professors for ratification; mark them as working decisions, hypothesis grade, until then.

## Verification before filing

- Before filing any instrument or claim-bearing artifact, offer adversarial verification: blind double-coding by independent agents plus refute-mode critics (construct, boundary, completeness). Precedents: the 2026-07-23 evaluability sweep, the 2026-08 path-coding rounds.
- Terminate adversarial loops with a PRE-DECLARED acceptance criterion (an agreement threshold plus "no blocking findings beyond wording changes") agreed before the run. Refute-mode critics never terminate on their own, and the researcher knows it.
- Before committing, show worked examples on real data. Expect definition probes on implicit constructs; state definitions explicitly in the artifact rather than leaving them distributed across rules.
- Document residual judgment calls in the artifact, never hide them. Unsure flags and sensitivity sets read as rigor here, not weakness.

## Standing handling rules

- Privacy findings: flag with exact locations, never touch the data, hand the decision to the researcher. Commits are held on unmasked material.
- Commissioned documents follow `_schema/voice.md` hard rules. Confirmation-gate outputs (ingest step-1 analyses, promotion asks, contradiction flags) are never compressed.
- Wiki and drafts output is read in Obsidian: one paragraph, bullet, or task per source line, never hard-wrapped.
